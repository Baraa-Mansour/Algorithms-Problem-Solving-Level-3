# Algorithms & Problem Solving Level 3

This project is a C++ practice workspace focused on intermediate algorithmic and problem-solving exercises, including matrix operations, string manipulation, file-based data handling, and recursion.

> Note: This project uses Windows-specific commands such as `system("cls")` in the `AddClients()` function inside `main.cpp`, so it is intended to run on Windows. If you want to run it on another OS, you may need to replace Windows console commands with platform-specific equivalents and use a compatible C++ build system.

## What this project is about

It is designed to help train and improve skills in:

- Matrix operations and 2D array processing
- String manipulation and parsing
- File I/O and simple record management
- Recursive and iterative algorithms
- Working with vectors and structured data
- Writing clean, modular C++ code

## Level

This repository represents Level 3 of the learning journey.

## How to run

1. Open the solution file named `Algorithms & Problem Solving Level 3.sln` in Visual Studio.
2. Build the project.
3. Run the program using F5 or the Run button.

## Topics covered in `main.cpp`

The code in `main.cpp` includes practice on:

- Matrix printing and manipulation
- Filling 2D arrays with random or ordered values
- Row and column sum calculations
- Matrix transpose and multiplication
- Checking matrix properties: identity, scalar, sparse, palindrome, equality, and typical matrix comparison
- Fibonacci sequence using loops and recursion
- String operations: first letters, uppercase conversion, and case inversion
- Word extraction, splitting, trimming, joining, reversing, and replacement
- Punctuation removal and vowel checking
- Client record management with file storage
- Reading, saving, updating, deleting, and displaying client records

## Tech Stack

The main goal is to practice solving algorithmic problems with structured functions and to strengthen C++ programming skills through focused exercises.
